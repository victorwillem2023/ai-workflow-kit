# Sources

The documents the app's numbers, rules and legal texts come from: a copy or an extract of the law, the price list, the
contract clause, the accountant's or the expert's sheet. One file per source, named after it, starting with where it comes
from (link, article, date) and when it was last checked. A spec for a sensitive change names these files under *Sources*
(`docs/workflow/SENSITIVE.md`). Never put personal data or a secret here.
